1 · Load MATSim output

Upload the three MATSim output files. They are sent to the server, which runs the Python converter — so large files are handled server-side, not in the browser. Network is required; plans enable route queries; events enable the delay query.

Network · output_network.xml

nodes + links

Plans · output_plans.xml

persons, activities, routes

Events · output_events.xml

timestamped events
Pipeline

Files → server parses & clips to your district → harmonises into TwIS objects/connections/values → emits a GeoJSON+CSV bundle (S4D-importable) and a graph.ttl (GraphDB) → answers cross-layer queries. The demonstration queries join network × plans × events on shared link ids.
